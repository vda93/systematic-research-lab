# BBO source rights and publication boundary

Raw Tardis Binance BTCUSDT native book-ticker data are proprietary and are **not included** in this repository. The code license does not license provider data. A reviewer obtains the data independently under the provider's applicable terms.

The [provider's use conditions](https://docs.tardis.dev/faq/general.md#what-can-i-use-the-data-for) permit research and sharing statistics/reports when raw observations cannot be reconstructed; they prohibit raw redistribution and data-access products. The stated publication exception excludes Coinbase, which is outside this study. The [CSV API documentation](https://docs.tardis.dev/downloadable-csv-files/api.md) describes free first-of-month downloads. Availability and terms can change; no paid access or credential is acquired by this project.

Only original code, protocol text, coarse aggregate results, source identities and hashes are published. No tick rows, event prices or per-intent outcome ledger is released. The aggregate disclosure is reviewed for reconstructibility; a source hash is an integrity identifier, not permission to redistribute the underlying file. Acquisition-time documentation identities are retained in [the receipt](bbo-acquisition.json). These summaries do not grant broader rights than the provider's terms or imply endorsement.

ECB observations remain governed separately by the frozen [ECB notice](../DATA_LICENSE.md). The two data sources are not silently covered by one license.
