# Historical evidence and public reproducibility

This portfolio presents original summaries of TradingBotHQ's actual historical research with AI-assisted engineering and writing. Selected aggregates were transcribed from completed reports and primary decisions. They are not generated by the synthetic experiment. The [evidence register](evidence.md) describes source access and limits; an unpublished ledger maps public claims to exact private sources and hashes.

Historical inputs are [data/historical-results.json](../data/historical-results.json). The [Matplotlib renderer](../scripts/render_historical.py) rebuilds four figures and an aggregate table. This checks presentation against public inputs. It does not independently recompute the original backtests, matched studies, account simulations or tester certificates. Raw vendor data, production code, account records and private evidence bundles are excluded.

The exact public inventory is release-files.json. The audit checks inventory equality, source types, local links, private-content patterns and Git history metadata. Output receipts identify public source and artifact hashes. Automated checks cannot authenticate unseen private evidence or prove every future disclosure safe.

The original [synthetic study](study.md) remains separate. Its outputs derive from [experiments/protocol.json](../experiments/protocol.json), and [results/study.json](../results/study.json) retains every declared calibration trial. Its protocol is a teaching specification, not an independently timestamped preregistration. Its methods use the standard library; historical figure reconstruction adds pinned Matplotlib. No credential or network input is needed after installation.

The verification command runs tests, audits public files and compares reconstructed artifacts with checked-in outputs. A saved result bundle includes hashes and refuses to overwrite an existing directory. CI runs the same public workflow. Cross-platform success is engineering evidence, narrower than independent historical replication or statistical validation.

Original public prose, code and figures are under [MIT](../LICENSE). This grants no rights to excluded vendor data, third-party strategy code or private artifacts. Legitimate existing public Git history is preserved; no private monorepo history was imported. Git metadata uses the owner's public noreply identity.
