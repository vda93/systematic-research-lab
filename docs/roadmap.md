# Work that requires new evidence

The portfolio preserves historical negatives. It does not need a profitable strategy to become a useful research record. These are future questions with their own gates, rather than repairs to spent holdouts.

- **Prospective evidence:** register a new question and access contract before genuinely new observations arrive. The public FX study's retrospective temporal holdout cannot become prospective evidence by renaming it.
- **Execution economics:** qualify timestamped bid/ask, financing, fees, instrument contracts and executable order assumptions before evaluating a deployable FX strategy. Official reference rates cannot supply those inputs.
- **Calendar recovery:** independently qualify a replacement MEDIUM-event universe before any unchanged MacroImpulse rerun. Preserve the invalid-universe verdict and the original mechanical output.
- **Selection-aware ORB research:** retain a complete synchronized configuration matrix and the full selection algorithm. Register nested selection and sequential validation rules before further access. Do not manufacture an overfitting probability from selected aggregates.
- **Operational assurance:** current-build, broker/runtime and deployment qualification are separate from historical semantic parity. No public portfolio gate authorizes private trading changes.

Optional machine-learning work belongs here only when a falsifiable question justifies its added complexity and it beats credible temporal baselines. It is not a completion requirement or a reason to reopen closed families.
